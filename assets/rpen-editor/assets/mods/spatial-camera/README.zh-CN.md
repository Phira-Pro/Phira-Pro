# 三维摄像机

在模组管理器启用后，“全局事件”增加三个种类：摄像机位置（X、Y、Z）、摄像机旋转（偏航、俯仰、画面倾斜）、摄像机镜头（视角）。7 列均可使用普通全局事件的缓动、首尾编辑、拖拽、复制、撤销和保存。

加载模组后，全局事件总览顶部显示“三维摄像机”工具区，包含“姿态过渡助手”和当前谱面的 UI / 背景跟随选项。点击“姿态过渡助手”打开独立的三维姿态编辑界面；模组管理器操作区及默认 Ctrl+Alt+C 也可打开。世界场景显示谱面平面及首尾两台摄像机，下方同时显示各自实际画面；“调整起始姿态 / 调整结束姿态”切换可拖拽对象，当前端高亮，另一端变暗。左键拖动摄像机本体自由移动，或拖动 X/Y/Z 轴约束移动；切换“旋转”后拖动偏航、俯仰及倾斜圆环。拖动空白或右键旋转观察视角，中键或 Shift+右键平移观察，滚轮缩放观察；这些观察操作不修改谱面摄像机。Shift 拖动姿态控件按 25 单位 / 5° 吸附。可框住全部、重置观察视角、数值微调、朝向谱面中心、复制另一端及交换首尾。

选择开始和结束拍、首尾姿态及缓动，可通过进度条与“动态预览过渡”查看实际过渡画面，一次生成 7 列事件、一步撤销。环绕、俯视、侧倾、拉近、拉远预设保留，可填入当前编辑端后继续拖拽修改。预设姿态同时计算摄像机位置和朝向，使其面向谱面中心，过渡中七轴分别插值；区间与已有摄像机事件重叠时拒绝生成，不覆盖旧数据。冲突或输入错误在生成按钮旁的固定提示区域显示，无需滚动，并暂停动态预览；修改参数后重新校验。姿态调整在生成前均为草稿，取消不写入；打开期间临时锁定其他编辑，关闭后恢复。

单选任意摄像机事件，在其独立属性页中有首/尾切换、调节条、快捷值和“在预览中拖拽”。选择起始值或结束值会定位到相应拍数，当前端选择在控件刷新及取样应用后保留；滑条、快捷值和预览拖拽均修改这一端，钩定事件仍同步首尾。取样时临时隐藏时间轴，拖动调整当前列，实时看到透视；应用一次写入历史，取消不改谱面。取样时其他编辑暂锁定，Esc 取消。取样期间可以滚轮浏览时间。

## 坐标与求值

谱面位于世界 Z=0 平面，X 向右、Y 向上。摄像机默认位于 (0,0,1000)，正对谱面中心；正面观察时减小正 Z 可拉近。X/Y/Z 允许 -50000–50000，跨到负 Z 后需转向谱面才能看到背面，处于平面上或背对几何时不会显示它。默认视角 `2 atan(450/1000)`，约 48.455°。该默认姿态与原预览完全一致，原有视野缩放和画面比例仍有效。视角是以 900 单位参考高度定义的透镜角度，竖屏或宽屏按原有逻辑裁切，不自动改变世界坐标比例。

偏航正值向右看，俯仰正值向上看，画面倾斜正值让画面顺时针转动。相机采用自由朝向；只改偏航/俯仰不会自动改变位置，要围绕中心运动可用助手的环绕预设。Y/Z 位移、旋转及视角各自求值，使用谱面 BPM 表、拍单位，不受当前判定线的倍率或父子关系影响。首个事件开始前使用该轴默认值，事件结束后保持尾值，缓动支持 1–29 及 Bezier。

相机基向量为 right、up、forward。世界点 P 相对摄像机 C 的三个分量分别是 `(P-C)·right`、`(P-C)·up`、`(P-C)·forward`，记为 u、v、d。焦距 f=`450/tan(FOV/2)`，预览缩放 s：

```
screenX = width/2 + u*f/d*s
screenY = height/2 - v*f/d*s
```

只显示近远裁面内的点。谱面保持二维平面，不为单独的线/音符添加 Z 属性；观察它的摄像机可以三维移动和旋转。远处压缩、近处放大和斜视透视来自同一透视投影。

## 渲染与交互

判定线、音符和打击特效优先直接使用 GPU 透视投影；静态素材纹理有容量受限的缓存，同一批可绘制多种贴图，避免每帧捕获、上传整张预览。没有透视倾斜时使用与相机投影精确等价的二维变换。重复铺贴、动画贴图、特殊画布滤镜等不适合此路径的绘制，自动使用动态世界窗口捕获，保留效果；相机和背景静止时复用背景投影。屏幕外音符和打击特效在保守边界外才跳过绘制，命中数据仅保留可见范围。噪域在原有状态与反转合成之前投影其几何，皮肤仍采样已经绘制的屏幕。只改变显示几何，不修改噪域、音符或判定线本身的坐标和事件语义。

“UI 和背景跟随谱面”位于全局事件总览的“三维摄像机”工具区，属于当前谱面，默认关闭。关闭时，背景和游戏 UI 留在屏幕位置；开启时，背景图片及游戏 UI 也放在 Z=0 平面，随同一相机产生移动、旋转、缩放和透视。背景原有的透明度、模糊以及 UI 的绑定与布局仍有效，正式预览、编辑背景预览、拖拽取样和过渡助手均会使用此设置。勾选即时写入可撤销的谱面修改，参与未保存提示与联机同步。不同谱面各自保存；旧版本保存在本机模组设置中的同名开关不再参与求值，缺少谱面字段时统一关闭。

顺序保持“背景 → 谱面物件 → 第一层 shader → 游戏 UI → 噪域 → 第二层 shader”，分别投影背景、物件和 UI；编辑器本身的工具栏与面板不参与投影。预览中的线、音符和噪域点击使用投影后的几何。常规判定线/噪域坐标取样期间临时使用平面视图，使其既有拖拽控制点继续对齐；结束取样后恢复摄像机。与“星航”声明冲突，避免把它基于平面距离的游戏碰撞规则用于透视后的场景。

世界窗口会跟随摄像机位置，侧移后仍可看到原画面范围以外的物件。靠近地平线时可见的无限平面以有限窗口近似，最大纹理尺寸及总像素有预算限制。模组设置中的流畅、均衡、精细主要影响需要捕获时的源纹理精度，不改变事件或几何求值。直接 GPU 路径保留素材分辨率。设备不支持 WebGL 或投影初始化失败时会提示并回到平面预览，保留摄像机事件。

## 文件与停用

事件保存于 Next 的 `globalEvents.version=1`，类型 ID 为 `spatial-camera/position`、`spatial-camera/rotation`、`spatial-camera/lens`；列 ID 分别为 x/y/z、yaw/pitch/roll、fov。标准 `startTime/endTime/start/end/easingType` 等字段沿用全局事件协议。来源自动记录：

```json
{"kind":"mod","id":"spatial-camera","name":"三维摄像机","author":"rpe-next","version":"1.0.0"}
```

每谱面选项位于 `globalEvents.types["spatial-camera/lens"].settings.followChart`，布尔值，缺省为 false。仅修改该选项也会写入包含来源和空 fov 列的 lens 类型，保证 Next JSON/PEZ 保存、停用保留及原 RPE 导出提示一致；后续生成镜头事件保留这个设置。谱面格式版本沿用全局事件的最低值 240。

保存后重开并启用此模组即可重现相机。停用时恢复平面渲染，移除工具和回调，事件保留为只读数据；不会删除事件。Next JSON/PEZ 保留全部事件，原 RPE 导出需要用户明确选择移除全局事件。模组本身不会自动启用或嵌入谱面。

联机编辑沿用全局事件的类型对象同步粒度，不提供逐摄像机事件锁；预览草稿只作用于本机，正式应用后才同步数据。其他软件需要自行支持这些全局事件才会呈现摄像机效果。
