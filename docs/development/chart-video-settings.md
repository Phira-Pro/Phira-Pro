# 谱面渲染设置项

入口为「设置 → 调试 → 谱面渲染」。先选择已下载谱面，再选择画面预设、调整参数，点击「开始渲染」。设置独立保存在 `data/render.yml`。

页面有六个可编辑分类，共 56 项。「参数总览」从同一份字段目录生成全部当前值，切换分类即可编辑。宽窗口双列设置，窄窗口单列设置；分类内容可独立滚动，底部导出进度与操作始终固定。页面不显示画面预览。

## 输出（4 项）

| 设置 | 范围与行为 |
| --- | --- |
| 分辨率 | 1280×720、1920×1080、2560×1440、3840×2160 |
| 帧率 | 30、60、120、240 FPS，不受显示器刷新率限制 |
| 输出目录 | 默认 `data/render/`，桌面端可选择目录 |
| 资源包 | 默认跟随当前游玩设置，也可选择内置 Phira 或任一已导入资源包；独立保存，不修改游玩选择 |

Windows 下另有编码器状态与按需安装按钮；这是工具管理操作，不计入参数数量。Android 自动发布到下载目录中的 PhiraPro。

所选资源包用于音符、双押样式、打击特效、打击音及结算音乐。固定选择按资源包标识保存，调整资源包列表顺序不会切换到其他包；所选包不可用时提示重新选择。

## 游玩画面（8 项）

| 设置 | 范围与行为 |
| --- | --- |
| 偏移指示器 | 跟随主游玩界面、开启、关闭；自动播放的判定偏移为零 |
| 判定线 AP/FC 指示器 | 独立控制判定线状态着色，自动播放同样生效 |
| 双押高亮 | 独立控制所选资源包的双押音符样式 |
| 打击特效 | 独立控制所选资源包的命中特效 |
| 显示准度 | 可在隐藏主游玩界面时单独显示 |
| 判定统计 | 显示各档数量，可在隐藏主游玩界面时单独显示 |
| Perfect 连击 | 替换主游玩界面的连击数，需要开启「显示游玩界面」 |
| Early/Late 统计 | 显示实际早晚判定数量，可在隐藏主游玩界面时单独显示 |

这些设置仅用于导出，不修改普通游玩偏好。偏移、准度、判定统计和 Early/Late 仍参与谱面噪域与效果合成。旧设置保留原画面：纯谱面不新增指示器，开启主游玩界面时偏移条随之显示。

## 演出流程（11 项）

| 设置 | 范围与行为 |
| --- | --- |
| 画面预设 | 纯谱面、Phira 游玩界面、Phigros 完整演出，循环切换 |
| 演出字体 | 可选 TTF / OTF，仅用于开场与结算，不改动应用字体 |
| 默认演出字体 | 恢复内置字体 |
| 导出开场 | 加载画面与曲目信息 |
| 导出谱面 | 谱面音乐与自动播放 |
| 导出结算 | 独立结算展示，不保存实际成绩 |
| 显示游玩界面 | 分数、连击、曲名及谱面绑定的界面 |
| 开场时长 | 1 至 60 秒，默认 5.8 秒，包含加载退场和判定线入场 |
| 游玩入场 | 0 至 5 秒，完整演出预设为 0 秒 |
| 游玩退场 | 0 至 5 秒，完整演出预设为 0 秒 |
| 结算时长 | 2 至 120 秒，默认 6 秒，包含游玩收尾和结算入场 |

至少开启一个导出阶段。预设切换保留已填写的元数据、玩家资料、音量和扩展配置，调整画面风格、阶段开关、游玩界面及入退场时长。完整演出预设已在开场和结算内编排过渡；开场后额外的游玩入场时长保持完整游玩画面，未启用开场时用于判定线与 HUD 入场。

## 开场（10 项）

| 设置 | 范围与行为 |
| --- | --- |
| 曲名 | 留空跟随谱面，游玩与结算共用 |
| 曲师 | 留空跟随谱面 |
| 谱师 | 留空跟随谱面 |
| 画师 | 留空跟随谱面 |
| 难度文本 | 留空跟随谱面，例如 IN Lv.15 |
| 等级数字 | 加载画面难度块，留空使用谱面定数 |
| 等级上标 | 可选附加文字 |
| 等级下标 | 可选附加文字 |
| 提示文字 | 留空使用谱面提示；谱面也未提供时，从 Phira Pro 游玩加载条目中抽取，每次导出保持不变 |
| 加载文字 | 留空显示 Loading... |

## 结算（17 项）

| 设置 | 范围与行为 |
| --- | --- |
| 玩家名 | 默认 Player，独立于登录账号，黑色底板随实际文字宽度伸缩 |
| 玩家头像 | 选择用于视频的本地图片 |
| 默认头像 | 恢复内置头像 |
| RKS | 留空隐藏，展示值为 0 至 100 |
| 课题牌子文字 | 留空隐藏 |
| 课题牌子颜色 | 中性、绿、蓝、红、金、彩，五色牌子使用内置背景素材 |
| 分数增加文字 | 可选，例如 +0000123 |
| 获得内容标题 | 默认“已获得” |
| 获得内容 | 留空隐藏整个获得内容面板 |
| 统计来源 | 自动演示统计或自定义展示 |
| 展示分数 | 自定义展示时可编辑，0 至 1000000 |
| 展示准度 | 自定义展示时可编辑，0 至 100% |
| 展示最大连击 | 自定义展示时可编辑，非负整数 |
| Perfect 数量 | 自定义展示时可编辑，非负整数 |
| Good 数量 | 自定义展示时可编辑，非负整数 |
| Bad 数量 | 自定义展示时可编辑，非负整数 |
| Miss 数量 | 自定义展示时可编辑，非负整数 |

正式导出默认使用本次自动播放的判定统计。只导出结算时采用满分示意。所有结算均带 AUTOPLAY 标识，展示参数不会生成、修改或上传成绩。

## 音频（6 项）

| 设置 | 范围与行为 |
| --- | --- |
| 混入打击音 | 支持 Click、Drag、Flick 和谱面自定义打击音 |
| 音乐音量 | 0 至 2，默认 1 |
| 打击音音量 | 0 至 2，默认 0.7 |
| 结算音量 | 0 至 2，默认 0.8 |
| 结算音乐延迟 | 0 至 10 秒，默认相对结算开始延迟 1.085 秒 |
| 音频淡入淡出 | 0 至 5 秒，默认 0.15 秒 |

开场与游玩入退场保持静音，谱面音乐从游玩阶段开始，结算音乐从结算阶段起点加所设延迟开始。混音峰值超过范围时统一归一化以避免削波。导出过程不播放声音。
