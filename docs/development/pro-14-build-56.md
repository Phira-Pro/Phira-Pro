# pro.14 build 56 源码更新

本轮仅推送代码，保留 `v0.8.2-pro.14` tag 和现有 build 55 Release，不覆盖产物。待测试确认后另行构建。

## 回放

- 修复结算保存后点击 RETRY 导致下一局没有录制缓冲的问题；同一 GameScene 可连续结算、重试并独立保存回放。
- 成绩历史原子写入并保存回放文件关联；新录制使用短哈希文件名，避免谱面路径转成过长文件名。
- 读取旧回放时校验数值并稳定排序乱序时间，保留同刻事件先后，不改写原文件；不能恢复旧文件缺失的打击过程。
- 新扩展名 `.ppr`，兼容 `.phirar` / `.phirarec`。iOS 文件选择包含通用数据类型，并注册新旧回放后缀及 `.ppp` 插件类型。
- F1、F2 等编号按每次按下到抬起的接触递增；移动保持编号，系统复用 ID 后的新接触重新编号，不代表固定物理手指身份。

## 判定、界面和练习

- 红黄保护、血条参数、流速、判定颜色允许正常计成绩；改变判定窗口、算法、详细档位等仍遵从成绩资格限制。
- 严判不再缩小 Perfect+；保留自定义提前／延后值。其余窗口按对应引擎规则处理，保证有效窗口单调。
- osu!mania ScoreV2 快捷项关闭 Perfect+，使用 [lazer ManiaHitWindows](https://github.com/ppy/osu/blob/master/osu.Game.Rulesets.Mania/Scoring/ManiaHitWindows.cs) 的实际半毫秒窗口：`floor(名义阈值)+0.5ms`。PERFECT 名义阈值在 OD≤5 为 `22.4−0.6OD`，OD>5 为 `24.9−1.1OD`；GREAT/GOOD/OK/MEH/MISS 分别为 `64/97/127/151/188−3OD`。OD −15～15 为本应用提供的扩展范围。
- 这套快捷配置的六档 ACC 按用户指定权重：100% / 300÷305≈98.36% / 2÷3≈66.67% / 1÷3≈33.33% / 1÷6≈16.67% / 0。该混合权重不等于官方统一以 305 为分母的 ScoreV2 ACC；分数、匹配和 Hold 机制仍使用当前 Phira 玩法。MEH 之外判为 MISS，不显示额外 BAD 档。
- 各档可设置 `#RRGGBB` 颜色，随预设／回放保存，应用到打击粒子、偏移条与结算名称。留空恢复资源包颜色；谱面作者指定的独立特效颜色继续优先。MISS 没有成功打击粒子。
- 结算状态条保留 UNRATED、OD、STRICT 等简短标记，完整信息点击查看。
- FPS 默认顶部居中，字号增大、增加半透明底衬，支持顶部／底部居中及四角；iOS 依据安全区避让。iOS 调试页新增 60／120Hz，设备允许时申请 ProMotion，并在窗口可用后重试安装显示驱动。系统省电、温控及设备能力仍可能限制帧率。
- 倍速、流速、练习起始速度和每圈增幅细化为 0.01x。
- 分段练习增加起止 combo 输入。按非假音符头部时间排序，同刻双押一起包含，区间覆盖选中 Hold 的尾部并留 250ms 前后量。支持自动循环与上一圈准度；时间输入和区间拖动继续保留。

## 插件

新增「设置 → 谱面 → 插件管理」，导入 `.ppp` Rhai 插件，默认关闭，支持启停、JSON 设置、删除和分析详情。提供谱面数据、结算数据和文字覆盖层接口。PPSR 等算法可由作者自行接入，当前没有内置 PPSR 或替换官服定数／RKS 的接口。

详见 [API 1 开发说明与可运行示例](../plugins/README.md)。
