# pro.14 build 57 本地更新

- Windows 在「设置 → 调试」增加帧率上限下拉框：跟随屏幕、60、120、144、165、185、200、240、360、480 FPS。选择后立即应用于菜单与游玩，并保存到配置。旧配置默认跟随当前窗口所在屏幕；移动到另一块屏幕时继续自动检测。手动档位控制应用的帧调度，不修改系统显示模式，实际帧率受性能和驱动影响。
- FPS 显示字号由 0.42 降到 0.30，底衬更小、更淡，位置移近屏幕边缘。顶部／底部居中与四角仍可选择，iOS 保留实际安全区避让，角落保留较小内缩。
- 插件管理移至「设置 → 通用」。插件使用普通 `.zip`，根目录仍是 `manifest.json` 和 `main.rhai`；导入流程校验包内容，不要求专用后缀。删除 iOS 的专用插件类型声明，继续通过系统 ZIP／通用数据类型选择文件。
- 插件开发文档与打包示例同步更新，详见 [Phira Pro Plugin API v1](../plugins/README.md)。此前 build 56 的 `.ppp` 命名和谱面页入口由本轮替代。

本轮在本地构建 Windows 包，版本为 `0.8.2-pro.14`、build 57，文件名保持 `PhiraPro-v0.8.2-pro.14-win64.zip`。现有 GitHub tag 与 Release 保持原状。

验证：214 项 Rust 单元测试通过；实际 OpenGL 回归验证 Windows 帧率下拉框选择、保存、重置同步，通用页插件入口，以及六种 FPS 位置在三种视口和模拟安全区下的边界。普通 ZIP 插件包经过实际导入、启停、谱面分析与结算回调验证。Android arm64 和 iOS 核心库编译检查通过；安全区模拟不代替移动端真机验收。
