# pro.14 build 58：统一调色盘

外部版本仍为 `0.8.2-pro.14`，内部 build 为 `58`。本轮只更新源码和本地 Windows 包，不替换现有 pro.14 Release。

- 设置 → 谱面 → 判定设置：每档判定颜色改用调色盘；标题右侧增加“恢复全部默认”。单档调色盘也可以恢复默认。默认值保留资源包回退标记，不写死为某个 RGB 值。
- 设置 → 调试 → 触点颜色：改为调色盘；同一行增加“恢复默认”，恢复应用默认红色，不改动触点大小或透明度。
- 设置 → 体验 → 上/下遮挡颜色：复用新调色盘，原有图片裁剪功能保留。
- 调色盘提供连续的饱和度/明度区域、色相条、十种常用色、RGB 三通道拖动和数值输入、`#RRGGBB` 输入，以及原始/当前颜色预览。弹窗随屏幕高度缩放。
- 在调色盘内选择颜色和恢复默认均为临时修改，点击“应用”后提交；取消或返回丢弃临时修改。设置行的恢复默认按钮则直接生效。
- 编辑预设时，颜色提交到预设草稿，保存预设才影响当前设置；取消预设草稿不会泄漏颜色修改。

## 验证

使用生产 UI 的隐藏 OpenGL 窗口，在 4:3、16:9、21:9 下验证调色盘渲染、单指拖动捕获和越界夹取、RGB/HEX 合法与非法输入、应用/取消/恢复默认，以及触点设置保存重载、预设草稿隔离和遮挡条颜色入口。截图和日志保存在本地 `target/judgement-panel-qa/`、`target/build58-ui.log`。

214 项库单元测试通过，生产 UI 回归通过，Android arm64 编译检查通过；调色盘同时检查了中文和英文布局。

Windows 构建使用 `scripts/build.py --platform windows --package` 生成正常版本名 ZIP；校验 ZIP 内容和校验和。移动设备实机表现仍需设备验证。
