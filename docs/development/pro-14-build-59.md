# pro.14 build 59：练习面板与辅助功能

外部版本为 `0.8.2-pro.14`，内部 build 为 `59`。本轮更新源码和本地 Windows 包，保留现有 pro.14 Release。

## 入口与操作

从谱面进入练习后，暂停即可打开练习面板。基础区域提供时间区间、Combo 区间、播放速度和自动循环；下方按类别展开辅助选项。时间和 Combo 的起止值使用并排的矩形输入框，速度可按 `0.01x` 调整。时间轴可定位当前播放时间，也可拖动蓝色／红色标记调整区间。

Combo 从 1 开始，按音符头时间排序；同刻音符一起保留，结束边界包含选中 Hold 的尾部，并在两侧添加最多 250ms 的余量。手动拖动时间边界后，区间改为时间区间。

原设置 → 谱面的变速练习、起始速度、每轮增速、失败重试次数与回退时长移入练习面板。已有配置会继续读取。设置 → 调试也改为同类矩形折叠分组，保留原有调试显示、帧率和触点设置。

## 新增选项

- **音频辅助**：变速不变调；正解音按音乐时钟在音符头时刻播放，支持原谱自定义打击音，避免与实际打击重复播放。音乐音量与音效音量分别生效。不变调采用流式 WSOLA；时间轴仍按谱面秒数推进，音高匹配的局部波形对齐范围为 ±8ms。
- **练习判定**：临时判定倍率为 10%～300%，同时缩放正负窗口；可切换为速度反向联动，使用 `1 / 当前播放速度`，随每轮提速更新。Phira Pro 与 Phigros 两种判定均读取运行时倍率，已保存的判定预设不被改写。
- **谱面揭秘**：视角缩放为 10%～500%，横纵平移为 -4～4 个谱面坐标单位，并提供视角复位。音符、判定线、噪域、触点判定坐标和调试叠加层随视角变换；暂停面板与 HUD 保持正常位置。谱面后处理在变换后的画面上执行一次。
- **判定范围**：按 Tap、Hold、Drag、Flick 分别显示／隐藏，设置透明度及预览时长；读取当前判定窗口、滚动轨道、速度、旋转和镜像。此项是辅助示意，不改变实际判定。判定线与音符调试开关也可直接在面板调整。
- **音符行为**：在原谱、Tap、Drag、Flick 之间循环切换；仅修改本次练习中的音符。恢复原谱时还原 Hold 长度与原打击音，不写入谱面文件。
- **片段书签**：输入名称保存当前片段，可载入、删除或同名覆盖；保存时间／Combo 区间、目标速度、循环、提速参数及上述练习选项。名称最多 48 个字符，每张谱最多 100 个书签。
- **多轮统计**：记录完整练习轮次的速度、准度、判定数和片段分数，并显示最佳轮次。保留最近 100 轮明细及当前组总轮数；修改区间、速度或影响音频／判定／音符的条件会开始新组，单纯调整视角或辅助显示不清空统计。手动定位后的残缺轮次不计入统计。

## 数据与适用范围

书签保存在应用数据目录的 `practice-bookmarks.json`，按谱面文件内容 SHA-256 区分；更换谱面文件内容后会视作另一张谱。书签采用临时文件替换写入；文件损坏时显示错误，不会静默覆盖为空库。Combo 书签载入时按当前偏移重新计算时间边界。

练习选项保存在应用配置中；音符转换、运行时判定倍率和每轮统计只作用于练习，不生成正常成绩，不改动磁盘谱面。正常游玩和回放继续使用原音频播放路径。

- 设置界面生产 UI 回归通过，检查折叠分组及现有调色盘、帧率、触点等控件。
- Android arm64 与 iOS 核心库编译检查；Windows 使用 `scripts/build.py --platform windows --package` 构建与打包，并检查 ZIP 完整性及可执行文件一致性。
