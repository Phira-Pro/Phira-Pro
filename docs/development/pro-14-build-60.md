# pro.14 build 60：原版练习布局与侧栏

外部版本为 `0.8.2-pro.14`，内部 build 为 `60`。本轮保留现有 Release，更新源码和本地 Windows 包。

- 恢复原版练习布局：返回／重试／继续按钮位置、右上速度滑条、中央区间时间轴、蓝／红／绿标记及白底时间输入框。Combo 区间、自动循环和上一圈准度仍在主界面。
- 左侧边缘的小箭头打开练习设置。新增音频辅助、渐进变速、练习判定、谱面揭秘、判定范围、音符行为、书签和统计全部放入侧栏，保留分类折叠和滚动。
- 侧栏沿用[原版多人面板](https://github.com/TeamFlos/phira/blob/main/phira/src/mp/panel.rs)的 0.5 秒三次缓动、左侧滑入和暗色遮罩，窗口有圆角。再次点击边缘按钮或点击侧栏外部即可收起。动画中和展开时拦截底下的练习控件，避免误触；中途反向切换保持动画连续。
- 谱面揭秘缩放低于 100% 时，使用金色边框标出正常视角可见区域。边框跟随视角缩放／平移，保持屏幕描边宽度；恢复正常比例后隐藏。边框不影响判定或噪域范围。

## 验证

223 项库单元测试通过。真实 GameScene / OpenGL 回归验证原版蓝色标记拖动、Combo 区间、自动循环、侧栏实际按钮、配置保存／恢复、原有回放功能，以及 4:3、16:9、21:9 下的 FXAA 渲染和高亮框像素位置。另检查侧栏缓动、中途反向及关闭前输入拦截。

Android arm64 和 iOS 核心库编译检查通过；Windows 从当前源码使用 `scripts/build.py --platform windows --package` 构建并校验包。截图与日志保存在本地 `target/replay-qa/practice-*.png`、`target/build60-*.log`。移动设备音质、性能和实际触控体验仍需真机验证。
