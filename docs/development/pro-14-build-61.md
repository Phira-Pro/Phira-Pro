# pro.14 build 61：练习侧栏与插件接口名称

外部版本保持 `0.8.2-pro.14`，内部 build 为 `61`。

- Combo 起点、终点两个输入按钮移入练习侧栏顶部；原版时间轴、速度滑条、时间输入框保留，自动循环按钮居中。
