# pro.14-fix1 更新与验证说明

发布 tag 为 `v0.8.2-pro.14-fix1`，应用显示版本保持 `0.8.2-pro.14`，内部构建号为 `67`。本次汇总 build 64～67 的比例、练习、回放皮肤、噪域分层、前后台恢复与触摸判定修复；安装包继续使用应用版本号命名。

## 修复内容

- 修复修改谱面比例后 HUD 越界：插件覆盖层每帧会切换到屏幕相机，游玩场景现在每帧明确设置谱面与 HUD 相机，不再仅在视口尺寸变化时更新。
- 单谱比例与全局「自定义游玩宽高比」共用居中适配逻辑。全局比例覆盖单谱比例；保留原有强制比例／自适应比例规则。
- 强制比例、比例值变化和窗口尺寸变化时，同步更新有效比例、相机缩放与视口。像素取整后的游玩区域始终位于父视口以内。
- 暂停与练习控件使用游玩区域的高度布局；控件触点换算包含视口偏移，绘制到后处理纹理时仍按屏幕上的游玩区域处理暂停输入。
- 绘制完成后恢复外层 UI 尺寸与相机，避免影响回放控制面板、插件覆盖层等界面。
- 修复单谱「强制宽高比」开关未标记谱面信息已修改的问题，保证单独切换此项也能保存。

## 回归方式

- 几何测试覆盖宽屏手机、4:3 平板及非零原点视口，验证单谱／全局比例等价、强制／自适应规则、视口边界及触点像素位置往返映射。
- 真实 OpenGL 回归覆盖三种父视口、四种比例设置、直接渲染／FXAA／MSAA，共 36 组配置。每组连续重设屏幕相机并渲染，检查分数区像素仍在游玩区域内，以及练习菜单可按绘制位置展开。
- 在本地临时恢复旧相机逻辑，同一回归在 `phone/chart-4x3/direct/frame-0` 检出分数区消失；实验结束自动恢复修复源码。
- 同时运行已有的回放播放、触点、练习区间、判定范围与插件回归。

复现命令（Windows PowerShell，在仓库根目录）：

```powershell
$env:RUSTFLAGS='--cfg record'
cargo test --locked -p phira --lib --no-default-features production_replay_transport_import_and_aspects -- --ignored --test-threads=1 --nocapture
```

渲染截图输出到 `target/replay-qa/aspect-*.png`。单元测试使用 `cargo test --locked -p prpr -p phira --lib --no-default-features`；运行普通构建前清除临时的 `RUSTFLAGS`。

build 64 本地结果：228 项单元测试通过（3 项图形测试默认忽略）；完整 OpenGL 回归通过。源码标识为 `41d28fd`。

## build 65：练习倍速、时间标记与回放皮肤

- 练习每次新进入时独立从 `1.00×` 开始，不继承局外倍速、夜店 Mod 的 1.5 倍乘数或上次开启的渐进变速；这些变化只作用于本次练习配置副本。书签仍可恢复保存的倍速及渐进变速设置。
- 修复暂停时练习场景吞掉所有触摸，导致原版倍速滑条和 `− / +` 按钮无法操作的问题；未处理的触摸继续交给 UI 控件。
- 滑条显示实际播放倍速。手动调整立即应用所选倍速并退出渐进变速，避免被渐进变速的起始值覆盖；起始值、每轮增幅和书签设置继续保留。
- 初始值、手动调速、重试及每轮渐进变速共用速度计算，按 `0.01×` 取整，音乐、谱面时钟及练习判定倍率同步更新。练习配置持久化不写回局外倍速和 Mod。
- 修复绿色播放位置标记拖动后被场景管理器恢复旧时间的问题。暂停中的拖动与书签跳转不再使用会撤销显式跳转的临时时钟；运行中的普通输入仍保留事件时间插值。
- 回放与正常游玩共用当前资源包选择，按用户所选资源包加载按键皮肤及音效，兼容未记录判定设置的旧回放。录制的判定、分数、偏移和倍速继续由回放决定。

新增回归包含真实的场景输入分发、更新与渲染：倍速拖动及两侧加减按钮，手机／平板／非整数比例下红蓝绿标记的连续拖动，暂停跳转与时钟恢复，音频在 0.10×～2.00× 间切换，以及新旧回放实际加载自定义资源包图片后切回默认包。

build 65 本地结果：233 项单元测试通过；完整 OpenGL 回归通过，包括上述倍速、三色标记与回放皮肤检查。

## build 66：噪域分层与练习前后台恢复

- 噪域在游戏 HUD 之前合成；暂停和练习操作控件放到最终谱面画面之后绘制，避免被噪域截图和后处理捕获。
- 后台暂停记住进入后台前是否已经暂停；回前台时保留练习暂停、位置和倍速。被中断的入场动画仍可继续，正常游玩等待用户主动继续。
- 恢复时只标记渲染缓存失效，下一有效绘制帧重建帧缓冲，覆盖 Surface 恢复后尺寸未变化的情形。
- 练习音频控制命令不再通过会等待消费者的有界通道发送，防止音频回调停顿时界面线程阻塞。恢复消费后仍按顺序应用暂停、跳转等命令。
- 界面绘制分层与应用生命周期分别拆到 `game/render_layers.rs`、`game/lifecycle.rs`；模块职责、已有耦合和新手审查方法见 [代码审查指南](code-review-guide.md)。

## build 67：同帧短点击与触点生命周期

- 合并 [PR #1](https://github.com/Phira-Pro/Phira-Pro/pull/1)，修复同一帧内按下又抬起的短点击被丢弃的问题。
- 持续按住的手指直接使用原生触摸快照，移除重复的按住触点缓存，防止已经抬起的短点击继续维持 Hold。
- 补齐触点 ID 复用时的噪域屏蔽清理，避免新手指继承上一次触摸的屏蔽状态；系统取消事件仍立即清除触点。

build 67 本地结果：237 项单元测试通过；两套判定、三种屏幕比例的同帧 Tap／Drag／Hold、取消触摸、静止 Hold 和触点 ID 复用回归通过，完整 OpenGL 回放与练习回归通过。
