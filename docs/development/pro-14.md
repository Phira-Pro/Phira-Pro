# pro.14 更新说明

版本：`0.8.2-pro.14`，构建号：`63`。本次替换原 pro.14 安装包，包含 build 55～63 的更新。

## 练习功能

- 保留原版练习主界面的速度滑条、区间时间轴、蓝／红／绿标记和白底时间输入框。新增配置统一放入左侧圆角菜单；与主窗口相连的小箭头可展开、收起菜单。
- 支持按起止 Combo 选择练习片段，同刻音符一起包含，结束位置覆盖选中 Hold 的尾部。Combo 输入、自动循环、失败重试次数、回退时长和多轮统计均在菜单内调整。
- 新增音频辅助：变速不变调、正解音播放；渐进变速可设置起始速度与每轮增幅。
- 新增练习判定倍率及速度反向联动，调整仅用于本次练习，保留已保存的判定预设。
- 新增「谱面揭秘」：缩放、平移视角和一键复位；缩小视角时以金色边框标出正常可见范围。
- 判定范围采用 Phira ad 的独立透明色带与描边，支持显示在判定线、音符或两处。可分别控制 Tap、Hold、Drag、Flick，调整 Tap／Hold 判定档位、Hold 尾部显示、透明度与前瞻时间。
- 新增「音符行为」，可在原谱、Tap、Drag、Flick 之间切换，随时恢复原谱。
- 新增命名片段书签，保存区间、速度、循环和练习选项；新增多轮统计，显示每轮速度、准度、判定数、片段分数和最佳轮次。

## 判定与成绩

- 严判模式保留 Perfect+ 的 16ms／用户自定义区间，其余档位按严判规则处理。
- 更新 osu!mania ScoreV2 OD 快捷区间，选择后自动关闭 Perfect+，应用随 OD 变化的 PERFECT 等档位。六档 ACC 权重为 100%／98.36%／66.67%／33.33%／16.67%／0。
- 红黄保护、血条参数、流速和判定颜色允许正常计成绩；调整判定窗口、判定算法等继续按对应成绩规则处理。
- 判定设置支持每档独立配色，颜色随预设和回放保存，并用于打击粒子、偏移条与结算名称。
- 倍速、流速、练习起始速度和每轮增幅细化为 0.01x。

## 调色盘与界面

- 重做统一调色盘：提供饱和度／明度区域、色相条、常用色、RGB 拖动与数值输入、HEX 输入和修改前后预览。
- 判定／打击特效颜色、触点颜色、上／下遮挡颜色使用同一套调色盘；支持单项恢复默认和判定颜色全部恢复默认。应用、取消与预设草稿分别保存，避免取消后仍保留修改。
- 调整结算状态条的字号与底板，以 UNRATED、OD、STRICT 等简短标记显示本局状态，点击可查看完整配置。
- 帧率显示缩小字号和底衬、靠近屏幕边缘，默认顶部居中；支持顶部／底部居中及四角六种位置，iOS 避让安全区域。
- 「设置 → 调试」改为矩形折叠分组，统一与练习菜单的控件样式。

## 回放修复

- 修复结尾、暂停倒计时等情况误清空录制，以及结算后重试导致下一局缺少回放的问题；连续游玩的各局分别保存。
- 本地成绩采用原子写入并保存回放关联，修复结算后从本地记录查看回放时偶发显示「无回放」的问题。
- 读取旧回放时稳定整理乱序时间，修复部分文件因「回放时间顺序无效」无法打开的问题；缺少判定事件的文件显示对应提示。
- 新回放使用 `.ppr` 后缀及短哈希文件名，继续读取 `.phirar`／`.phirarec`；修复 iOS 文件选择器无法选中回放的问题。
- 触点编号按每次按下至抬起的一次接触递增，移动过程中保持编号，系统复用触点 ID 后重新编号。
- 修复上／下个失误定位、逐帧操作跳到曲首／曲尾，以及触点显示与控制问题；调整触点大小或透明度时自动开启显示。
- 统一播放器按钮与时间轴对齐，录制信息显示判定事件、触点事件及帧数。

## 插件管理

- 新增「设置 → 通用 → 插件管理」，导入普通 `.zip` Rhai 插件，支持启停、设置、删除和分析详情。
- 接口正式命名为 **Phira Pro Plugin API v1**，提供谱面数据、结算回调和文字覆盖层，可供 PPSR 等分析算法接入。
- 提供插件开发说明与可运行示例：[Phira Pro Plugin API v1](../plugins/README.md)。

## 谱面与平台

- 支持读取、游玩 rpe-next Next 兼容模式导出的噪域谱面，包括生命周期、多段激活、移动、旋转、缩放、反转和预警。使用官方噪域贴图、折射与辉光效果，连续区域先合成再描边。
- Windows「设置 → 调试」新增帧率上限，支持跟随屏幕或 60、120、144、165、185、200、240、360、480 FPS，选择后立即应用并保存。
- 修复 Windows Release 回归测试的编译配置，并单独检查完整图形回归测试套件的编译。
- iOS「设置 → 调试」新增 60／120Hz 选项并接入 ProMotion 刷新率申请。
- Android「设置 → 调试」新增 60、120、144、165、185、200、240Hz 选择及设备最高刷新率显示，恢复应用或显示模式变化后重新申请。
- 修复 iOS 数据迁移／批量导入的临时文件处理，减少重复复制与内存占用。
- Android、iPhone 和 iPad 使用横屏，同时保留左右两个横屏方向。
- README 更新至当前功能，特别感谢中加入 Phira Mod++ 和 Phira ad。

## 下载

由 GitHub Actions 构建 Windows x64、Linux x86_64、macOS arm64、Android arm64-v8a 和 iOS arm64 安装包，文件名保持版本号命名。iOS IPA 未签名，安装前需自行签名。
