# pro.14 更新说明

版本：`0.8.2-pro.14`，构建号：`55`。

## 新增

- 支持读取、游玩 rpe-next Next 兼容模式导出的噪域谱面，包括噪域生命周期、激活区间、移动、旋转、缩放、反转和预警。显示沿用现有官方噪域贴图与效果，连续区域先合成再描边。格式与验证范围见 [rpe-next 噪域兼容说明](rpe-next-noise.md)。
- Android 在「设置 → 调试」中新增刷新率选择：60、120、144、165、185、200、240Hz，默认 120Hz；同时显示设备报告的最高刷新率。按当前分辨率选择不高于目标的可用显示模式，没有符合条件的模式时回退到最低可用模式。设置会保存，并在恢复、显示模式变化和 Surface 重建后重新申请；实际刷新率和帧率仍受设备、系统省电及温控策略影响。

## 回放修复

- 修复结尾时间回退、暂停倒计时等情形误清空整局录制的问题，改用明确的重试状态识别新一局；暂停和结尾界面操作不再混入游玩触点。
- 对缺少逐音符判定事件的旧回放明确提示，保留原成绩与导入、导出功能。已经丢失的打击过程和触点无法恢复，需要更新后重新录制。
- 修复上／下个失误定位、逐帧操作跳到曲首／曲尾，以及触点显示与控制问题；调整触点大小或透明度时自动开启显示，并展示当前数值。
- 统一控制台按钮与时间轴对齐；录制信息增加判定事件、触点事件及帧数。缺少或稀疏的帧表使用明确标注的参考步长。

## 界面与平台修复

- 调整结算界面状态条的字号和底板，按本局配置标注判定体系、osu!mania ScoreV2 OD、STRICT MODE、自定义区间、倍速等；点击可查看具体窗口和启用项。
- 修复 iOS 数据迁移／批量导入的临时文件处理，减少重复复制与内存占用，失败时保留具体 IO 原因。
- Android、iPhone 和 iPad 强制使用横屏，同时保留左右两个横屏方向。

## 验证说明

回放修复已用 Exoplanetary Mirage 对应谱面完成真实 GameScene 录制、重试、暂停、结尾、导出、导入及播放回归。测试使用确定性输入验证新录制流程，不恢复或替换原玩家的回放。噪域及回放画面回归运行于 Windows OpenGL；Android 编译检查和模拟不同视口不等同于所有移动设备的真机验收。

安装包由 GitHub Actions 按同一 tag 提交构建：Windows x64、Linux x86_64、macOS arm64、Android arm64-v8a、iOS arm64。iOS IPA 未签名，安装前需自行签名。
