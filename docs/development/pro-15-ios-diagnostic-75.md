# pro.15 iOS 启动诊断版 · build 75

本预发布用于排查旧设备覆盖升级 pro.15 后的黑屏退出，仅提供 iOS IPA。应用版本仍为 **0.8.2-pro.15**，内部构建号为 **75**。

- 在图形初始化前创建说明文件和启动阶段日志，供系统“文件”App 或电脑文件共享访问。
- 日志包含应用版本、构建号、UTC 时间及最后执行的初始化阶段。
- 重开应用时保留上一轮启动日志；捕获到启动错误时额外保存错误报告。
- 保留原有谱面、成绩、设置数据目录，日志不上传。

请使用原有签名方式及应用标识覆盖安装，打开应用复现后，在“文件 → 浏览 → 我的 iPad → Phira Pro”或电脑应用文件共享中导出以下文件：

- `PhiraPro-startup-log.txt`
- `PhiraPro-startup-previous.txt`（存在时）
- `PhiraPro-startup-error.txt`（存在时）

反馈时附上设备型号、完整系统版本、安装方式及复现时间。若仍没有生成日志，也请说明这一结果。
