# 本地曲包与显示设置

本轮在 `0.8.2-pro.16` 上增加内部构建号至 **83**，已完成本地开发和 Windows 打包，随后按用户要求提交并推送；不更新标签或 Release，不再次构建安装包。

## 判定与游玩背景

- 实时游玩、练习与回放共用 AP/FC 状态判断。PERFECT+、PERFECT 保持 AP 金线；GREAT / GOOD / OK / MEH 转为 FC 色，BAD / MISS 转为普通色。谱面自定义的判定线颜色仍按谱面处理。
- 两套判定产生的 Drag/Flick 成功命中，在记录和计分前归入最高启用的完美档位：PERFECT+ 开启时使用 PERFECT+，关闭时使用 PERFECT。旧回放按原有记录播放。
- 「设置 → 谱面 → 游玩背景模糊」范围为 `0.00–1.00`，步进 `0.01`，默认 `0.50`，对应原有的 50px 模糊。`0.00` 不模糊；越接近 `1.00` 模糊越强。设置只影响游玩背景，不改变判定或成绩资格。

## 启动更新检查

首页后台检查本仓库公开的稳定 Release，比较 `pro.N` 和 `fixN` 的数字版本，不使用原版 Phira 的版本号。保留更新说明、取消、忽略此版本、打开 Release 页面等原有弹窗行为。离线模式跳过检查，网络请求有超时，不阻塞首页。

实现使用 [GitHub Releases REST API](https://docs.github.com/en/rest/releases/releases#get-the-latest-release)。同一标签重新上传附件不会改变版本比较结果；更新提示以新的正式版本标签为准。

## 曲包使用

1. 本地谱面库首位固定显示「谱面合集」，收藏夹筛选内也保留入口。多选和课题选曲时不会误进入合集。
2. 合集内竖向卡片靠左排列，支持横向滚动；末尾的 `+` 可导入 ZIP 或从本地库多选创建曲包。
3. ZIP 支持包含多张 `.pez` / `.zip` 谱面包，带元信息的谱面目录，以及带配套音频和曲绘的 PEC / JSON。复用正式谱面导入器，并保留 RPEN 等格式警告。中途失败会清理本次新建的谱面目录。
4. 本地谱面创建曲包只保存引用；合集元数据保存到应用数据目录下的 `songpacks.json`，不复制已有音乐和曲绘。命名后持久保存，重启可继续使用。
5. 曲包详情左侧为原 `ChartsView` 的两列卡片，单击原地选曲。右侧保持 16:9 清晰曲绘，背景使用所选曲绘的模糊图，切换时渐显。下方显示曲名、评级、分数、准度和开始游玩按钮。
6. Mods、编辑、收藏、信息、菜单、预览和游玩继续复用 `SongScene` 的处理。编辑后的卡片文字同步刷新；删除曲包内谱面时清理引用并切换到下一张。
7. 有内置官方合集资源的构建继续提供原官方合集入口。

## 模块与验证

- `phira/src/songpacks.rs`：本地曲包元数据与 ZIP 导入。
- `phira/src/page/coll.rs`：合集展示、创建、导入。
- `phira/src/scene/song/pack.rs`：复用单曲场景的选曲布局和背景加载。
- `phira/src/updates.rs`：公开 Release 检查与版本比较。

常规核心和应用回归、背景模糊端点、嵌套 PEZ/ZIP 与原始 PEC 导入、持久化去重、失败回滚和路径校验均通过。真实 OpenGL 回归直接执行页面/场景点击与滑条拖动，检查选曲、工具栏、开始游玩和三种屏幕比例，并导出 `target/songpack-qa/` 画面。

本轮电脑操作工具在初始化时连续崩溃；系统原生文件选择器与文本输入框的鼠标操作未完成复验。图形回归及生产导入器验证与这项限制分别记录。
