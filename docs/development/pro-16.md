# 更新说明

pro.16，应用内版本 **0.8.2-pro.16**，内部构建号 **81**。

## 判定显示与玩法

- 「设置 → 谱面」加入「显示判定详情」，在分数与准度下方实时显示各档数量，随当前判定预设显示对应档位。
- 名称完整显示为 PERFECT+、PERFECT、GREAT、GOOD、OK、MEH、BAD、MISS，逐行右对齐，采用各档指定颜色与 50% 不透明度。
- 加入「显示 Perfect Combo」：连击显示仅累计连续 PERFECT+ / PERFECT，其他判定中断；普通最大连击及计分规则保持原有逻辑。
- 单曲 Mods 加入「音符行为」，可选择原始、全 Tap、全 Drag、全 Flick。转换后可正常游玩和结算，不计入成绩。
- 全局严判与单曲严格判定 Mod 独立保存，任意一处开启即生效；同时开启只应用一次，Perfect+ 保持配置区间。

## RPEN 谱面适配

- 支持整体曲线轨迹、切线旋转、判定线 BPM 倍率与 skewControl 音符倾斜控制。
- 支持分层噪域、各层独立叠加与新版反转规则。没有指定自定义皮肤时继续使用官方噪域材料。
- 接入自定义噪域皮肤参数、多 Pass、命名目标、历史纹理、外部纹理与低性能通道，提供 NoiseField / Ocean 资源。
- 支持谱内 shader 事件、参数轨道与叠加顺序，加入 30 种扩展 shader。
- 识别 globalEvents，并适配 spatial-camera 的位置、旋转、视野与跟随设置，同步处理音符、判定线、噪域、粒子及触点映射。其他第三方全局事件仍需对应提供者适配。
- 导入使用这些扩展的谱面时显示早期测试警告，默认开启；可在谱面信息中关闭「RPEN特性」回退旧版行为。

## 回放与练习

- 回放触点可触发噪域按压显示及音频效果，不受「显示触点」开关影响。
- 修复正反逐帧跳转缺少打击特效的问题，跳转重建不重复累计分数或重播历史打击音。
- 修复练习目标准度步进与输入的百分比换算错误。
- 纳入 PGR 重叠事件、最终事件端点及零时长插值修复。

## 布局、诊断与刷新率

- 主页播放器与游玩按钮、谱面库课题按钮与列表分别使用独立 HUD 布局，不再随另一项缩放或移位。
- 游玩按钮中的曲绘按固定 HUD 区域裁切，正方形或竖向曲绘不会改变按钮尺寸；优化换图过渡。
- 问题诊断加入开始 / 停止采样，离开页面是否继续由跨页面开关控制；优化输入记录与预览，减少采样时的卡顿。
- 优化 Android 浮窗、多窗口、焦点和前后台切换时的刷新率重新申请，补充显示状态诊断。
- 优化 iOS 窗口恢复后的刷新率请求，调整恢复判断以区分呈现等待和实际渲染负载。
- 补充启动阶段日志、历史日志保留及 iOS 文件共享说明，便于定位启动异常。

## 背景音乐

- 修复有效音量变化未同步到播放器的问题。
- 静音时显示播放图标和提示，用户点击播放即可恢复声音并保存音量；保留主动暂停状态。
- 优化恢复播放时的淡入处理，支持重新尝试加载失败的音乐。
- 验证自定义背景音乐连续循环、暂停及恢复；自定义音乐模式不随机切换本地曲目。
