# pro.18 制谱工作台

入口为「设置 → 调试 → 制谱工作台」。Windows 使用独立的应用所属编辑窗口，Android 和 iOS 使用应用内网页视图。编辑器按窗口实际可用区域布局，与播放器的谱面显示比例分别管理。

## 模块边界

当前固定 RPEN **0.14.0** 正式标签合并后的 Pro fork 提交，升级说明见 [pro.19](pro-19.md)。升级保留上游祖先与 Pro 适配历史，不将生成前端重新纳入主仓库。打包范围包括动画曲线、调速曲线、音高图、空间轨迹、着色器编辑、内置皮肤、视频渲染模块及其离线依赖和许可；fork 回归检查相对模块、Worker 和静态 URL 依赖是否都进入了打包（未被剔除表跳过）。

- `rpen-host/` 提供本地资源服务、分块持久存储、受限试玩、导出和异步谱面副本请求，不依赖播放器、账户、成绩或 Rhai 插件。
- `phira/src/editor/` 负责资源准备、平台窗口、试玩和谱面副本适配。谱面库读写集中在 `library.rs`，通过既有新谱面导入流程创建副本，不改变判定、成绩或旧插件接口。
- `assets/rpen-editor/` 是构建期生成的制谱器前端，已被 `.gitignore` 排除，不随仓库分发。`phira/build.rs`（`build_support/editor_assets.rs`）按 `scripts/editor/upstream.json` 固定的 Pro fork 提交浅克隆上游，读取该提交内的 `phira-pro-exclude.json`，剔除其中列出的开发用路径后打包其余全部文件，再生成网页资源索引。剔除表只列开发内容，上游新增文件默认进入打包，合并上游时不必对账。桌面、Android、iOS 都是先编译 `phira` 再收集资源，因此三条构建路径自动执行，无需额外步骤；离网构建或只需播放器时可设 `PHIRA_SKIP_EDITOR_ASSETS=1` 跳过，此时产物不含制谱器资源。
- Pro 的桥接、触屏、布局代码、上游文件的局部修正和剔除表都提交在 [Phira-Pro/rpe-next](https://github.com/Phira-Pro/rpe-next) 上，本仓库只固定提交。`UPSTREAM.json` 记录上游版本和提交。升级时在该仓库推送新提交，再把提交号写进 `scripts/editor/upstream.json`，同步检查模组 API、平台存储契约、导出格式和原生播放兼容性。
- `scripts/editor/overlay/` 存放尚未进入 fork 的临时修正，构建时叠加在固定提交之上，`overlay.lock.json` 记录每个补丁所依据的上游文件大小与 CRC32。基线按 LF 换行记录，Windows 工作区检出 CRLF 与 CI 检出 LF 得到同一份基线。上游文件变化后构建会中止并提示复核，避免补丁静默失效；修正合入 fork 并更新固定提交后应删除对应 overlay 条目。当前条目为模组装载：`src/ui/mod-runtime.mjs` 包装固定提交中的同名模块，`src/ui/mod-modules.mjs` 按依赖顺序把包内模块改写为 Blob URL 并直接导入入口，使 iOS 的 WebKit 不再依赖后注册的 import map；模块图存在环时回退固定提交的 import map 流程。包装模块同时用 `export *` 转发固定提交的全部导出，其它模块引用的符号不会在链接阶段缺失。

上游界面的局部修正保留在对应模块：`src/ui/hotkey-settings.mjs` 明确设置非提交按钮类型，防止录入、清除、还原和导入导出操作关闭外层 `method="dialog"` 表单。快捷键持久化仍通过原有保存回调完成。
`src/ui/settings.mjs` 仅为具有默认值的设置创建重置按钮，信息展示区不提供空操作。

本地服务只监听回环地址，使用会话随机地址校验来源；存储接口仅处理编辑器自己的记录和素材。网页不取得任意文件系统、账户、原生命令或成绩接口。写入按临时文件落盘后替换，项目保存比较版本以阻止旧会话覆盖。

桥接层只对明确列出的存储读取命令自动重试：读取记录、工程及恢复列表、版本号、素材分块、存储状态与迁移状态。网络传输中断时依次等待 400、1200、2400 毫秒，最多重试 3 次；所有尝试及等待共用原请求的超时上限，超时不会重新起算。HTTP 错误、业务错误、无效 JSON、写入及未知命令不自动重放。独立连接提示在初始化阶段同样可见，恢复后短暂显示，失败时提示保留窗口、备份未保存内容并确认未完成操作；不会自动刷新页面或重复提交保存、删除、导出。

静态资源路径先执行一次 UTF-8 URL 解码，再检查目录分量和实际文件边界。中文、空格和编码后的井号可用于资源名；目录穿越、反斜杠、绝对路径、无效 UTF-8 及二次编码路径被拒绝。

## 工程与试玩

工程、恢复副本、扩展包、扩展设置、皮肤和版本历史使用 RPEN 的分块存储接口。工程标识转换为受控记录名，素材按内容引用保存；清理仅处理未被提交记录或活动保存引用的素材，回收站中的工程继续保留素材。

「Pro 试玩」先保存工程，然后生成独立 PEZ 快照。可选择从头、当前播放头或指定秒数区间，在原生练习模式中加载；缺少音乐时提示补充。试玩不挂接成绩上传、PB、正常历史或回放保存回调。「返回编辑器」保留网页会话，因此播放头、判定线、事件层、选择和撤销历史不因试玩重建。

工程原文件不会被播放器写回。未知模组全局事件不会作为原生 JavaScript 执行，检测到未支持的提供者时阻止该试玩请求并保留工程；编辑器预览和导出仍可使用。

0.13.2 的自定义判定线动画曲线仅在 Pro 试玩及谱面库副本中使用上游烘焙器转换为分段事件，保留 BPM、线倍率及原 RPEN 工程。转换后仍有自定义曲线的噪域或扩展事件时，阻止生成原生快照并明确提示；这不代表播放器直接支持新的曲线定义。RPEN 视频下载转交已有 Pro 导出接口，网页视图的编码能力及宿主导出体积限制仍适用。Electron 专有的超大谱磁盘存储与系统集成功能不由网页容器自动获得。

「从 Pro 导入」通过本次会话的临时键查询谱面列表并读取只读谱包，网页不接收原生目录路径。当前工程先保存，再使用显式导入接口创建独立 RPEN 工程；多谱包需要选择具体谱面。「存入 Pro 谱面库」从当前编辑内容生成 PEZ，丢弃输出副本中可能过期的原生元数据，由当前资源绑定生成信息；原工程素材保持不变。原生侧为每次写入分配新的 UUID 目录，名称追加「（RPEN 编辑副本）」，重名时编号且不堆叠副本后缀，清除在线标识和上传者，不复制成绩。索引保存失败或导入中途关闭时回滚本次新目录。

谱面副本操作通过有截止时间的异步请求交接，服务线程不会等待原生页面处理而阻塞其他请求。列表键、操作键和快照键限定为会话内的不透明标识，包读取只能消费一次；目录边界、符号链接和资源总量分别检查。

存入前检查音乐绑定。缺少封面时只在新目录中生成默认深色封面并绑定，避免空资源路径让正常选谱启动失败；已有资源不被覆盖。

## PC 关联 RPE 素材

Windows 的「迁移 RPE」使用原生目录选择器关联用户选定的 RPE 主目录。仅扫描根目录的 RPE 配置及 `Resources/`，跳过符号链接并检查解析后的目录边界、深度、文件数量和大小。实际目录只记录在本地宿主索引中；网页仅取得相对资源名和内容标识，不能自行指定原生路径。

转换后的谱面、设置和新增素材保存为独立 RPEN 数据；JSON、PEC 和文本描述另行保存，避免原 RPE 再次保存谱面或修改绑定后使独立 RPEN 工程无法打开。未修改媒体通过内容标识读取原目录，不复制到宿主素材库。普通保存、恢复副本和版本历史统一经过相同存储接口，克隆后的素材也按内容核验后复用引用；新增或已修改素材仍保存到独立素材库。缩略图等派生数据继续单独保存，关联不意味着完全不产生新数据。

首次读取及原文件时间或大小改变后核验内容，避免把变化后的素材冒充已保存版本。源目录被移动、文件变化或读取失败时，保留 RPEN 工程记录并提示恢复原目录或重新关联；重新迁移时可沿用已有的重复处理流程。删除 RPEN 工程、回收站清理和素材清理均不删除原 RPE 文件。导出 PEZ、逐谱工程库备份、Pro 试玩和存入 Pro 谱面库仍按需读取素材生成自包含快照。

不回写原 RPE 工程，不自动删除旧迁移生成的副本。Android 和 iOS 沿用原迁移流程；PC 关联工程跨设备使用时应先导出包含素材的 PEZ。

## RPEN 扩展

保留上游模组解析器、依赖和冲突检查、资源、设置、命令、预览钩子、全局事件注册及紧急停用机制；保留 `@rpen/` 导入路径。RPEN 扩展与 Pro 的 Rhai 插件分别安装和管理。桌面 Electron 或 Node 专用能力不会因为加载到网页视图而自动获得，通用网页模组是主要兼容对象。

浏览器编辑工具生成普通音符和事件时可直接进入原生试玩。新增全局事件、Shader 或其他播放语义需要播放器实现对应协议；不能用编辑器可执行模组替代原生兼容性检查。

完整工程库可从 RPEN 设置中的导出功能备份。桌面上游的程序自更新和外部存储目录搬迁不接入宿主；编辑器资源随 Pro 版本更新。

## 触屏与布局

保留 RPEN 原有文件栏、播放栏、工具栏、轨道、右侧属性和底栏的控件顺序及皮肤组织方式。宿主在原文件栏追加谱面库副本操作、「Pro 试玩」和「返回 Pro」，不另建替代工具栏。触屏和窄窗口可在原位置收起各个面板，右侧属性面板收为侧边把手，展开后恢复原有控件。

触屏常驻文件栏将图标、曲名和菜单合为一行，菜单空间不足时横向滚动，保留原有按钮顺序及右侧对齐。播放、工具、轨道的折叠入口各为短按钮，共占一行；展开一个时隐藏另外两个及其入口，关闭后恢复三按钮。右侧属性标签取消固定定位，随具体属性内容一起滚动。非顶部分组的面板偏好从旧版迁移，原有工程和扩展设置不受影响。

「启用触控滑动编辑区域」位于原版「在实时预览中显示游戏 UI」按钮左侧；皮肤重新组织控件后也保持这一相邻关系。启用时，音符与事件画布的单指拖动只调整播放头，不传给左键放置、拖拽或框选处理；关闭后恢复触控编辑。鼠标与键盘保持原来的行为。「触控操作」弹窗提供框选、多选和键盘动作映射，使用原有命令处理入口。

触控滑动模式中向下拖动推进播放头，向上拖动回退，两个编辑区保持一致；双指缩放和普通编辑手势沿用原有方式。

音符放置在单指松开后提交，双指手势取消待放置物件并调整时间轴比例；取消、失焦和切换工具清理未完成手势。编辑器铺满自身视口，不为摄像头区域整列缩进。面板状态只保存在独立的编辑器偏好键中，不重建控件、不改写工程，也不改变播放器布局。

工作台原生文字使用 Pro 现有页面渐变，网页容器在原生进入动画完成后打开。RPEN 加载时用独立启动屏遮住未完成的编辑区，等待首页、皮肤、模组及字体准备好后再展示；加载失败可重试或返回。关闭时先保存工程与偏好，再渐隐网页并回到原生页面渐变。

Android 启动屏使用独立原生控件，网页准备完成后通过受限桥接移除。启动时的返回按钮与系统返回直接通知编辑器宿主，不依赖网页脚本或本地 HTTP 请求；载入超时或主页面网络错误会提供重试及停用扩展重试。网页初始化阶段和桥接请求均有截止时间，停用扩展重试不删除扩展包或工程。
HTML 仅声明 `pro/editor.mjs` 一个模块入口，由它显式依赖上游 `src/ui/app.mjs`，避免上游与宿主各自的入口在扩展动态模块映射初始化期间并行启动。

## 验证

- `cargo test --locked -p rpen-host`：分块记录和二进制素材读回、保存冲突、路径和快照校验。
- `node --test scripts/tests/editor_touch.test.mjs`：双指取消放置、缩放、单指提交、取消、两个编辑画布的触控滑动，以及鼠标和预览画布不受影响。
- `node --test scripts/tests/editor_boot.test.mjs`：启动模块未就绪及请求停滞时退出、初始化截止时间、早期脚本失败与安全重试、加载界面移除和分组切换。
- `node --test scripts/tests/editor_library.test.mjs`：异步副本交接、失败和超时，以及导出使用当前谱面、不改写来源素材。
- 桌面操作验收包括导入、四类音符及事件编辑、撤销重做、保存重开、扩展导入和启停、窗口比例、原生试玩及返回。移动平台需分别在系统网页视图和实际触屏上验收，桌面窄窗口不能代替移动真机结果。

Android 构建从当前证书验证依赖生成网络安全资源，保留其证书吊销检查规则，仅增加回环地址例外，避免覆盖既有联网能力。制谱测试使用独立应用标识，并单独记录实际验证范围；不以此替代视频渲染或其他既有功能的完整验收。

当前接口限制：单次工程记录 256 MiB，单个媒体文件 512 MiB，试玩包 512 MiB，展开资源总量 1 GiB。超限请求会明确失败，不覆盖已经保存的工程。
