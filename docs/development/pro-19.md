# pro.19 更新说明

应用版本为 `0.8.3-pro.19`，构建号为 `96`，基础版本继续使用 `0.8.3`。iOS 系统版本同步为 `0.8.19`，不沿用上一修复版的 `-fix1` 后缀。

## RPEN 0.14.0

在独立 Pro fork 中合并上游 `v0.14.0` 正式标签，主仓库通过 `scripts/editor/upstream.json` 固定合并后的提交。保留资源排除清单、原作者 cmdysj 的署名、LICENSE、NOTICE 和新增皮肤素材的独立许可。生成的前端仍不加入主仓库。

同步的编辑器功能包括空间轨迹、二维移动、事件数值缩放、着色器代码编辑和模板、RPE Classic 皮肤及其配套布局、操作按键显示，以及上游取样、选择、预览和渲染修复。皮肤配套布局通过 RPEN 自身的模组管理方式自动启停。

已有 Pro 存储、读取重试、移动端面板和触控命令、关联 RPE 素材目录、谱面库副本与原生试玩继续保留。iOS 模组依赖仍由既有加载补丁处理，保持全部上游导出与释放行为。

## 快照与素材

Pro 试玩和「存入 Pro 谱面库」共用快照准备接口：先转换原生可支持的自定义动画曲线，再使用 RPEN 0.14.0 的着色器导出流程准备源码，最后生成独立 PEZ。未修改原工程、素材表及来源谱面；缺失的自定义着色器明确报错，避免生成看似成功但丢失效果的副本。

原生快照中的着色器事件保留在主谱面中，移除 RPEN 为其他播放器额外镜像到 `extra.json` 的同一组事件，避免重复应用或按不同附加格式再次解析；视频、BPM 和其他附加字段保留。普通 RPEN 导出的行为不变。

新增空间编辑与模组工具能在编辑器内运行，并不代表其所有运行时协议都已由原生播放器实现。原有不支持的扩展曲线与模组效果继续阻止误导性的原生试玩。

## 内嵌原生预览与界面

设置 → 预览新增 RPEN / Phira Pro 选择。Pro 模式复用原生 `ChartVideoRenderer` 和游戏配置，在 GL 线程离屏绘制，通过本机宿主的有界最新画面接口在同一预览区域显示。编辑修改使用独立快照自动同步，时间以 RPEN 音频时钟为准；原生端静音，无成绩写入。画面最高 960 × 720，原生采样为 30 FPS，传输按需更新，关闭和替换会释放旧会话。错误明确显示，可重新连接或切换渲染器。

RPE Classic 在 Pro 内保留顶部文件菜单，将其高度计入布局缩放。图标和名称留在左侧，按钮单行靠右，空间不足时可横向滑动或用滚轮查看。取消空的三点工具页按钮，在原位置放置左侧无边框滚动箭头和白底触控操作按钮。其他皮肤恢复原触控位置。

新增日本語语言入口及主要编辑、设置、宿主操作文案。专业工具尚未翻译的条目使用英文回退，语言说明中明确显示此范围。

Inkline、Classic 与内置目录同步提供日语标签。启动入口在导入界面模块前从宿主恢复语言，避免本机服务地址变化后回到默认语言。原生预览在准备画面时遮蔽 RPEN 渲染层，跳转时清理过期命中特效，连续播放按音频时间推进特效。

## 容器能力边界

整个编辑器画面的录制使用 RPEN 桌面版专用捕获桥，Pro 的网页容器没有提供该接口，不将其列为 Pro 可用功能。谱面视频渲染继续走 Pro 保存通道，编码支持取决于系统网页视图。操作按键显示沿用上游实现。

## 验证入口

- fork：`node --test test/*.test.mjs`，包含新增内置及自定义着色器快照、缺失素材拒绝和原工程不变的回归。
- 主仓库：`node --test scripts/tests/editor_*.test.mjs`、`cargo test --locked -p rpen-host`，以及版本与打包脚本检查。
- Windows：`python scripts/build.py --platform windows --package`，核对固定提交、资源索引和新增皮肤／模组依赖，再验证编辑器进入、保存、导出和返回。
