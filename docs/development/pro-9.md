# pro.9

版本：`0.8.2-pro.9`。Android `versionCode` 与 iOS `CFBundleVersion` 均由 `43` 提升至 `44`。

## 排行榜重构

- 榜源与排序指标分开切换：上方选择「Pro榜 / 混合榜 / 本地记录」，在线榜下方选择「分数 / 无瑕度 / 准度」。界面统一使用「Pro服」「Pro榜」名称。
- 重新设计排行榜面板，扩大列表空间，采用半透明背景与渐变过渡边缘，让谱面背景继续透出；移除明确的外侧描边和关闭按钮，点击面板外的空白处关闭。
- 混合榜合并官服与 Pro服返回的成绩，按当前指标排序，同一玩家保留较优成绩。每条记录标明来源，**不显示混合名次**。
- 「我的排名」固定在列表上方，官服与 Pro服各占一行；谱面页进入排行榜的入口也分别显示两服名次。
- 官服个人名次沿用原版的 `/record/list15/{chart}` 获取方案，直接使用服务器返回的名次；Pro服个人名次通过独立名次接口获取，不受前 20 条列表限制。两服名次分别加载，榜单列表加载失败不会覆盖另一项已获取的名次。
- 区分加载中、暂无成绩、未登录、离线和暂不可用等状态。混合榜某一榜源加载失败时，仍展示已获取的成绩并提示部分数据不可用；支持刷新按钮与下拉刷新。
- 本地记录继续按当前谱面展示本机保存的游玩成绩，点击记录可查看详情。补齐各语言的排行榜文案。

Pro榜展示服务器返回的前 20 条成绩。准度只能对已返回的成绩排序，两服均不提供准度名次；混合榜也不计算跨服名次。

## 文字显示修复

- 修复排行榜淡入时，主分数、准度及下方明细可能持续不可见或异常变淡的问题。重复文字复用字体缓存时，现在按每次绘制的实际透明度显示，不再沿用第一次绘制的透明度。
- 补充重复分数、无瑕度明细和准度文字的淡入、淡出渲染检查，以及数字文字的宽度与可见边界检查。

## Android 修复

- 整理原生壳的初始化、Surface 生命周期和触摸转发，修正系统输入框所需的 Material3 主题配置与触摸预处理兼容性。
- 修复数据目录、缓存目录在 JNI 环境初始化前被读取成占位字符串，导致启动后尝试写入错误路径并立即崩溃的问题。现在使用回调传入的 JNI 环境读取实际路径。
- 补齐配置保存所需的原子写入辅助函数：在目标目录写入临时文件、同步完成后替换原文件，避免失败写入直接截断已有配置。

## 验证范围

排行榜排序、同玩家去重、混合榜不显示名次、官服返回名次的解析与保留，以及原子写入回归通过。文字布局检查与桌面真实 GPU 渲染检查通过，覆盖三种指标的重复文字淡入、淡出，以及内置字体在 80%–120% 显示大小下的居中与裁切。

Android 10 / API 29 实体平板上已验证本轮启动修复与此前构建的覆盖安装，并通过截图复现排行榜文字消失的问题。最终包含文字修复的 pro.9 arm64 APK 已构建成功，版本与签名校验通过；尚未将该最终 APK 安装到平板复验。桌面渲染检查不替代 Android 实机检查；本轮未完成 iOS IPA 构建与实机验证。
