# 回放使用与兼容说明

本说明对应 pro.12 build 49 的源码和本地构建，不代表 build 48 的已发布附件包含这些功能。

## 文件管理与分享

从「设置 → 谱面 → 回放文件管理」进入独立管理页，也可从单谱本地记录或成绩详情进入。支持单文件导入、导出、删除，以及全部／自己录制／导入回放／缺少谱面筛选。删除回放会保留成绩历史和谱面。

回放使用 `.phirar`，不包含谱面、音乐、曲绘或资源包。导入先保存到回放库，再寻找本地谱面：新录制使用谱面和玩法附加数据的内容指纹匹配，另行校验音乐文件；谱面改名或更换曲绘不会改变谱面指纹。同一音乐重新编码后的文件字节不同，也会提示音乐版本不一致。

缺少谱面时可手动关联；在线谱可前往对应谱面页面下载，返回后重新匹配。回放记录了历史下载地址时，可下载并校验「录制版本」，以独立本地谱面安装，不覆盖当前在线版本。下载后的内容仍须通过校验，不能静默使用同名或同 ID 的错误版本。服务器不同会提示先切换服务器；内容一致的本地谱仍可匹配。

导入记录显示在关联谱面的本地记录中，保留原玩家、原日期和原始成绩，并标注导入来源。来源和规则筛选只影响本地列表。导入不写入本人历史、PB、RKS、游玩次数或上传队列。文件中的昵称、账号 ID 和成绩是录制信息，不代表服务器验证。

相同回放重复导入不会重复入榜。独立 ID、事件内容和玩家身份用于识别重复项；不同玩家使用相同 ID 不会相互覆盖。缺少原始成绩的旧回放显示「成绩未记录」。

## 播放器

底部控制台提供播放／暂停、重播、前后 5 秒、时间轴拖动和观看倍率。可隐藏控制台；展开分析时为谱面保留独立视口，保持录制比例。暂停拖动后保持暂停，播放中拖动后恢复播放；应用切到后台再返回也保留暂停状态。

- 观看倍率：0.1／0.25／0.5／0.75／1／1.5／2／3 倍，与录制速度分别显示。
- 逐帧：前后 1／10 个实际录制帧；无帧表的旧格式使用明确标出的 60Hz 参考步长。
- A–B 循环：先设置 A，再在至少 50ms 后设置 B；设置 B 后启用循环，可单独开关或清除。
- 失误定位：时间轴标出 BAD／MISS，可跳到上一处或下一处，并提前 1 秒观察。
- 触点：显示开关、编号、大小和透明度；编号是界面中的 F1、F2 等，文件保留完整原始 ID。不同手指独立插值。
- 分析：显示已记录的真实有符号误差；非计时判定另作标注。判定范围使用录制配置，旧格式未记录配置时不显示推测窗口。
- 录制信息：显示玩家、日期、来源、谱面版本、校验状态、原成绩、判定配置、录制速度、偏移、Mods 和部分玩法设置。

播放应用录制的判定事件，不按观看者的当前预设重新判定。跳转时恢复分数、连击、长条和触点；静默快进不补播打击声音或特效。检查点按谱面音符数限制容量，超大谱面可退回从头恢复。

## 格式与本地存储

v5 文件结构为 8 字节 `PHIRAREC`、小端 `u32` 版本号 5，以及 Zstandard 压缩的 UTF-8 JSON。Rust 类型和读写实现在 `phira/src/replay.rs`，本地索引与匹配在 `phira/src/replay/library.rs`。

新录制保存独立 ID、玩家信息、原始时间与成绩、谱面引用和指纹、音乐指纹、判定设置、计分相关选项、录制速度／偏移／Mods、视口比例、实际帧时间、完整触点 ID、判定事件和真实误差。它不保存完整资源快照；观看设备的资源包及其他未记录的视觉偏好仍可能改变画面外观。

继续读取 Pro v3／v4 和 JPhiraRec v0／v1。旧文件导出或导入时转换为 v5 容器，但只补充能可靠取得的元数据；不会凭空产生旧误差、配置、帧表、身份或原始成绩。旧版程序不能读取 v5。

回放放在用户数据目录的 `replays` 内。`index.json` 单独保存导入时间、本机关联路径、校验结果和去重信息；这些本机绑定不写进分享文件。读入和解压数据均有 128MiB 上限，事件数量及数值也会校验，损坏文件报错。

## 验证范围

自动回归覆盖 v3／v4／v5、JPhiraRec 压缩变体、Unicode 与长路径、完整触点 ID、非零真实误差、配置和扩展判定序列、损坏文件、重复导入及跨玩家 ID 冲突。

Windows 上使用真实 GameScene、OpenGL 和音频后端回归：重命名谱面匹配、音乐／谱面版本不一致拒绝、导入本地榜且不污染历史、长条跳转、检查点恢复、暂停拖动、实际逐帧、A–B 循环和录制版本安装；另生成 4:3／16:9／21:9 的播放器、分析区和管理页截图检查。Android 构建与 iOS 真机文件选择／保存流程的验证结果应以本次交付记录为准，不能由 Windows 界面回归推定。
