# RPEN 0.13.1 播放兼容

固定上游为 [`7b46dc0923deee6d10d14a9dc5adf92e8cecc66f`](https://github.com/kclg-YSJ/rpe-next/tree/7b46dc0923deee6d10d14a9dc5adf92e8cecc66f)。本轮保留已有整体轨迹、噪域分层及皮肤、谱内 shader、三维摄像机、BPM 倍率与距离控制曲线，在以下方面补齐播放器行为。

- 零时长激活条保留预备闪烁，到达目标拍后结束，不产生持续激活。瞬时条不会截断其他激活条；同起点条目合并预闪参数，生命周期外的条目不产生预闪。
- 普通判定线、噪域、全局事件和 shader 参数统一使用精确 Bezier 求值，处理双 X 为 0 或 1、端点和反向跳转；普通事件缓存保留完整 f32 控制点，避免相邻曲线共用错误缓存，速度事件也加入 Bezier 缓存；启用新版速度计算时，Bezier 不再被当作线性速度，积分按曲线精确计算。
- 音符同时接受 `hitsound` 和旧字段 `hitSound`、`tint` 和旧字段 `color`。规范字段优先；空音效名回退旧字段或音符默认音效。`judgeArea`、`tintHitEffects` 保持原有实现。
- 谱内存在 `tap.mp3`、`drag.mp3`、`flick.mp3` 等同名素材时，优先使用实际素材；缺少这些文件时继续支持原有内建音效名。
- 推断音乐时排除音符引用的音效，尊重显式音乐引用；音乐为空或文件缺失时，不再把其他音频误选为音乐。有效入口信息仍优先，媒体绑定不要求展示元数据全部齐备。

直接放置、黄条曲线、音符追踪等编辑工具导出普通音符和已有事件，不需要播放器执行编辑操作。任意第三方 JavaScript 模组仍不属于可直接执行的谱面能力；未知全局事件提供者保留原有诊断。

## 回归入口

`scripts/qa/rpen_0131_reference.mjs` 从固定上游生成 `prpr/tests/fixtures/rpen-extensions/v0131.json`，覆盖 Bezier 极限控制点和噪域瞬时预闪。原有轨迹、摄像机和 BPM 样本继续保留。

Rust 回归覆盖上游期望值、倒退求值、多种画面比例、实际谱面解析中的字段优先级、控制点缓存、速度事件和音乐推断。图形回归继续使用 `production_replay_transport_import_and_aspects`，检查生产导入、shader、噪域与离线回放。

## 练习模式与功能清理

修复 [#6](https://github.com/Phira-Pro/Phira-Pro/issues/6)：拖动结束标记或输入结束时间时，暂停光标保留当前位置；超出新区间时限制在最近的边界。音频、谱面显示时间和判定进度同步，区间统计重新计算，未完整播放的区间继续标记为部分练习。

本轮移除内置多人房间、网络会话、实时观战、悬浮入口及其设置、专用资源和桥接代码。视频渲染保留独立选谱与详情设置，离线回放及已有文件导入继续保留。
